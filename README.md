# MTG 録音メモ

ブラウザだけで動く MTG 録音 / 文字起こし / AI要約アプリ。

## 利用者向けガイド

GitHub Pages で公開: https://coolura.github.io/voice-transcriber/guide.html

## 管理者向け: Apps Script のセットアップ

GAS URL を `index.html` の `GAS_URL` 定数に設定するための手順です。

1. [Google Apps Script](https://script.google.com/home) を開く
2. 「新しいプロジェクト」を作成
3. `apps-script/Code.gs` の内容を全部コピーして貼り付け、保存
4. 右上の「デプロイ」→「新しいデプロイ」
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」→ 初回は権限確認に従って許可
6. 表示された **ウェブアプリ URL** を `index.html` の `const GAS_URL = '...'` に設定
7. `apps-script/Code.gs` の `SPREADSHEET_ID` に、管理DBとして使う自分のスプレッドシートIDを設定
8. デプロイした Web アプリ URL にアクセスして、管理DBに「利用者設定」シートを自動作成
9. 「利用者設定」シートに利用者行を追加
   - `利用者ID`: クライアントに渡すログインID
   - `初期パスワード`: クライアントに渡す初期パスワード
   - `利用者名`: 会社名・担当者名など
   - `有効`: `TRUE`
10. コミット & プッシュ

コード更新時は「デプロイを管理」→ 編集 →「新バージョン」→「デプロイ」で反映（URL は変わりません）。

利用者追加・パスワード初期化は、Apps Script を編集せず管理DBスプレッドシートで行います。初回ログイン後、`初期パスワード` は自動で空になり、`パスワードハッシュ` に保存されます。

利用者ごとの保存先（スプレッドシート ID / Notion DB ID / Notion トークン / Gemini API キー / プロンプト）は、ログイン後の設定画面で利用者自身が入力します。設定値はブラウザではなく、管理DBスプレッドシートの「利用者設定」シートに保存されます。

録音後の保存履歴はブラウザ内の履歴ではなく、利用者の保存先スプレッドシート / Notion DB から取得して表示します。旧バージョンのブラウザ内履歴DBは起動時に削除されます。
