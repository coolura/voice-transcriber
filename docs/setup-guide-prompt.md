このマークダウンファイルは、AI（ChatGPT / Claude / Gemini など）に渡して、**クライアント向けの環境設定マニュアル**を生成させるためのプロンプトです。

===== ここから AI に渡すプロンプト =====

あなたは、IT に詳しくない一般のビジネスユーザー向けに、わかりやすいシステム導入マニュアルを作成するテクニカルライターです。

これから「MTG 録音メモ」というブラウザアプリの初期セットアップ手順書を作ってください。

## 🎯 作成するもの

- **対象読者：** IT に詳しくないクライアント（経営者・営業担当者・事務担当者など）
- **形式：** Word（.docx）または Notion ページにそのまま貼り付けられる Markdown
- **想定所要時間：** ユーザーが資料を見ながら 15〜20 分で完了する分量
- **ゴール：** ユーザー自身がスマホから MTG を録音 → Notion に自動保存できる状態にする

## 📱 アプリの概要（資料の冒頭に書く内容）

「MTG録音メモ」は、ブラウザだけで動くシンプルな MTG 議事録作成ツールです。

- スマホやPCのブラウザで MTG を録音すると、
- AI が自動で文字起こし＆要約し、
- 指定した Notion データベースに保存します。

**特徴：**
- アプリのインストール不要（URL を開くだけ）
- 保存履歴は保存先のスプレッドシート / Notion から表示
- Notion に自動でページが追加される
- ログインすれば別の端末でも同じ設定を利用できる

**公開 URL：** `https://coolura.github.io/voice-transcriber/`

## ⚙️ 資料に含めるべきセクション（必須）

以下の章立てで作成してください。各ステップにスクリーンショット差し込み箇所（「📷 スクリーンショット挿入：〇〇」のような注釈）を明記してください。

### 1. はじめに
- このアプリで何ができるか（1ページ）
- 全体の流れ図（録音 → 文字起こし → AI要約 → Notion保存）
- 準備するもの一覧
  - Google アカウント
  - Notion アカウント
  - スマホまたは PC（Chrome または Edge ブラウザ）

### 2. 全体の流れ（このマニュアルの目次）
1. Gemini API キーを取得する（5分）
2. Notion インテグレーションを作成する（3分）
3. Notion にデータベースを作成する（3分）
4. 保存先のスプレッドシートを用意する（2分）
5. アプリにログインしてキーと保存先を入力する（3分）
6. 接続テストを行う（1分）

### 3. ステップ1: Gemini API キーの取得
- アクセス先: https://aistudio.google.com/app/apikey
- 手順を 1ステップずつ番号付きで書く
- 📷 スクリーンショット挿入箇所を明記
- **取得したキーは "AIza..." で始まる文字列**であることを明記
- 注意事項:
  - キーは他人に絶対に教えない
  - 無料枠で十分（個人利用なら課金される心配なし）
  - 紛失した場合は再発行可能

### 4. ステップ2: Notion インテグレーションの作成
- アクセス先: https://www.notion.so/my-integrations
- 手順:
  1. 「+ 新しいインテグレーション」をクリック
  2. 名前を入力（例: `MTG録音メモ`）
  3. ワークスペースを選択
  4. 「送信」をクリック
  5. 表示された「シークレット」をコピー（**`ntn_` で始まる文字列**）
- 📷 スクリーンショット挿入箇所
- 注意事項:
  - シークレットは他人に教えない
  - メモ帳などに一時的に保存しておく（次のステップで使う）

### 5. ステップ3: Notion データベースの作成と接続
- Notion で新しいページを作成
- `/database` と入力 → 「データベース（フルページ）」を選択
- データベース名を「MTG録音」などに設定
- **データベース ID の取得方法：**
  - データベースを開いた状態でブラウザの URL を確認
  - `https://www.notion.so/【32文字のID】?v=...` の **32文字部分** がデータベース ID
  - 📷 URL の見方を図解
- **インテグレーションに接続：**
  - データベース右上「…」→「接続先」→ ステップ2で作ったインテグレーションを選択
  - 📷 スクリーンショット挿入箇所

### 6. ステップ4: 保存先のスプレッドシートを用意する
- 手順:
  1. https://sheets.new で新しいスプレッドシートを作成（名前は任意、例:「MTG録音」）
  2. ブラウザ上部の URL から **スプレッドシート ID** を取得
     - URL は `https://docs.google.com/spreadsheets/d/ここがID/edit#gid=0` の形式
     - `/d/` と `/edit` の間の文字列がスプレッドシート ID
  3. このスプレッドシート ID を次のステップで使うのでメモしておく
- 📷 URL からスプレッドシート ID を確認するスクリーンショット挿入
- 注意事項:
  - スプレッドシートの共有設定の変更は不要（自分のアカウントで使うため）
  - シート名やヘッダーは自動作成されるので、スプレッドシートの中身を触る必要はない

### 7. ステップ5: アプリへの設定登録
- https://coolura.github.io/voice-transcriber/ を開く（スマホでもPCでもOK）
- 管理者から案内された **利用者ID** と **パスワード** でログイン
- 「⚙️ 設定」を開く
- 入力項目:
  - **利用者名：** 会社名や担当者名など、識別しやすい名前
  - **Gemini API キー：** ステップ1で取得したキー
  - **スプレッドシート ID：** ステップ4で取得した ID
  - **Notion DB ID：** ステップ3で取得したデータベース ID
  - **Notion トークン：** ステップ2で取得したシークレット
- 「💾 保存」をクリック
- 📷 設定画面のスクリーンショット挿入
- 💡 設定はログイン中の利用者情報として保存されるため、別のPCやブラウザからも同じ設定を利用できる
- ⚠️ NotionトークンやGemini APIキーは保存後に再表示されない。変更する場合だけ新しい値を入力して保存する

### 8. ステップ6: 接続テスト
- 「🔗 接続テスト」ボタンをクリック
- 数秒後「✓ 成功」と表示されることを確認
- Notion のデータベースを開いて、テストページが追加されていることを確認
- 失敗した場合のチェックリスト:
  - キーや URL が正しく貼られているか
  - Notion データベースにインテグレーションが接続されているか
  - スプレッドシート ID / Notion DB ID / Notion トークンが正しいか

### 9. 使い方クイックガイド
- 録音手順を 3 ステップで:
  1. クライアント名を入力 or 録音
  2. MTG 日を選択（デフォルトは今日）
  3. MTG 内容を録音 → 停止 → 「✨ AI要約 & Notion 保存」を押す
- スマホのホーム画面追加方法（iOS Safari / Android Chrome 別）

### 10. よくある質問（FAQ）
- Q: マイクが使えないと言われる
  - A: ブラウザのマイク権限を許可してください（手順を記載）
- Q: 何回まで使える？
  - A: Gemini 無料枠は1日 1,500 リクエスト程度、個人利用なら十分
- Q: データはどこに保存される？
  - A: テキストと要約はログイン中の利用者設定に紐づいた Notion / スプレッドシートに保存し、アプリ内の保存履歴も保存先から表示
- Q: 他人にこの URL を教えていい？
  - A: アプリ利用には利用者IDとパスワードが必要。IDとパスワードは第三者に共有しない
- Q: API キーの管理はどうすべき？
  - A: 第三者に共有しない、紛失したら再発行する
- Q: コストは？
  - A: 基本無料（Gemini API 無料枠＋ Notion 無料プラン＋ Google Apps Script 無料枠）

### 11. トラブルシューティング
- 「録音ボタンを押しても認識中のまま」→ Chrome / Edge を使用、マイク権限の確認
- 「Notion 送信失敗」→ Notion DB ID・トークンの確認、データベース接続の再確認
- 「AI要約失敗」→ Gemini API キーの確認、月の上限を超えていないか
