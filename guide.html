MTG 録音メモ - セットアップガイド

初回設定の手順です。5〜10 分で完了します。

このアプリでできること

  • ブラウザだけで MTG を録音・文字起こし
  • AI（Gemini）が自動で議事録を要約
  • Google スプレッドシート / Notion に自動保存
  • ログインすれば別の端末でも同じ設定を利用

アプリのインストールは不要です。Chrome または Edge でアクセスするだけで使えます。

1. Gemini API キーの取得

AI 要約に使う Gemini API のキーを取得します。

  1. Google AI Studio を開く
  2. Google アカウントでログイン
  3. 「API キーを作成」をクリック
  4. 表示された AIza... で始まるキーをコピー
無料枠で十分です。個人利用で課金される心配はありません。
API キーはパスワードと同じです。他人に教えないでください。紛失した場合は再発行できます。

2. スプレッドシートの準備

MTG 記録の保存先となるスプレッドシートを用意します。

  1. 新しいスプレッドシート を作成（名前は任意）
  2. ブラウザ上部の URL を確認
  3. /d/ と /edit の間にある長い文字列をコピー

URL の例:

https://docs.google.com/spreadsheets/d/1abcDEFghiJKLMnopQRstuVWxyz/edit#gid=0

この場合、スプレッドシート ID は 1abcDEFghiJKLMnopQRstuVWxyz です。

シート名やヘッダーは自動作成されます。スプレッドシートの中身を編集する必要はありません。

3. Notion の設定（Notion に保存する場合）

Notion に保存しない場合はスキップできます。

3-1. Notion トークンの取得

  1. Notion インテグレーション を開く
  2. 「新しいインテグレーション」をクリック
  3. 名前を入力し、ワークスペースを選択して作成
  4. 作成後の画面で「内部インテグレーションシークレット」をコピー

コピーした ntn_... で始まる文字列が Notion トークンです。

トークンはパスワードと同じ扱いです。他人に教えないでください。

3-2. Notion DB ID の取得

  1. Notion で保存先にするデータベースを開く
  2. 右上の「…」→「接続」から、作成したインテグレーションを追加
  3. データベースの URL をコピー
  4. URL 末尾の 32 文字の英数字が DB ID です

URL の例:

https://www.notion.so/example/36b1e4c4319e80c3bb45f8e6251a16f9?v=xxx

この場合、DB ID は 36b1e4c4319e80c3bb45f8e6251a16f9 です。

データベースにはタイトル型のプロパティ「名前」を用意してください。

4. Google カレンダー連携（任意）

アプリ画面に直近のカレンダー予定を表示したり、カレンダー自体を埋め込むことができます。MTG前のスケジュール確認に便利です。

カレンダー機能を使わない場合はスキップできます。

4-1. Google Cloud Console で OAuth クライアント ID を取得

カレンダーの予定を読み取るための認証情報を作成します。

  1. Google Cloud Console を開く
  2. 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前（例: mtg-recorder）を入力して作成
  3. 左メニュー「APIとサービス」→「ライブラリ」を開く
  4. 検索欄に Google Calendar API と入力 → 表示された API を選び「有効にする」をクリック
  5. 左メニュー「APIとサービス」→「OAuth 同意画面」を開く
    • User Type: 外部 を選択 →「作成」
    • アプリ名（例: MTG録音メモ）、ユーザーサポートメール、デベロッパー連絡先メールを入力
    • 「保存して次へ」を最後まで進める
    • 「テストユーザー」に自分の Google アカウントを追加
  6. 左メニュー「APIとサービス」→「認証情報」を開く
  7. 「+ 認証情報を作成」→「OAuth クライアント ID」を選択
  8. アプリケーションの種類: ウェブアプリケーション
  9. 名前（例: MTG録音メモ Web）を入力
  10. 承認済みの JavaScript 生成元 に以下を追加:
    • https://coolura.github.io
  11. 「作成」をクリック
  12. 表示された クライアント ID（xxxxx.apps.googleusercontent.com の形式）をコピー
「承認済みの JavaScript 生成元」が間違っているとログイン時にエラーになります。https://coolura.github.io（末尾スラッシュなし）を正確に入力してください。

4-2. カレンダー埋め込み URL の取得（任意）

アプリ内に Google カレンダーを iframe で表示したい場合に必要です。

  1. Google カレンダー を開く
  2. 左サイドバーの「マイカレンダー」から表示したいカレンダーにマウスを乗せる
  3. 「…」（オプション）→「設定と共有」をクリック
  4. 下にスクロールして「カレンダーの統合」セクションを探す
  5. 「埋め込みコード」の中にある src="..." の URL 部分をコピー
    • 例: https://calendar.google.com/calendar/embed?src=自分のメール&ctz=Asia%2FTokyo
非公開カレンダーでも、自分が認証してログインしていれば iframe 内で表示されます。

4-3. アプリの設定画面に入力

  1. MTG 録音メモ を開き「⚙️ 設定」を展開
  2. 「📅 Google カレンダー連携（任意）」セクションに入力:
    • クライアント ID — ステップ 4-1 で取得した xxx.apps.googleusercontent.com
    • 埋め込み URL — ステップ 4-2 で取得した URL（任意）
    • 表示件数 — 直近何件の予定を表示するか（デフォルト 5）
  3. 「💾 保存」をクリック
  4. 画面に「📅 Google カレンダー」カードが表示される
  5. 「Googleでログイン」をクリック → アカウント選択 → 「許可」をクリック
  6. 直近の予定一覧が表示される
  7. 「🗓 カレンダー表示」をクリックすると、埋め込みカレンダーが下に展開される
初回ログイン時に「Google によって確認されていないアプリ」と表示される場合があります。「詳細」→「（アプリ名）に移動」で進めます（自分が作ったアプリなので安全です）。

4-4. うまく動かないとき

  • 「origin not allowed」エラー → Google Cloud Console で承認済み JavaScript 生成元に https://coolura.github.io を追加しているか確認
  • 「access_denied」エラー → OAuth 同意画面のテストユーザーに自分のアカウントが追加されているか確認
  • カレンダーが表示されない → 埋め込み URL が正しいか、カレンダーの共有設定を確認
  • ログインしても予定が出ない → Google Calendar API が有効になっているか Cloud Console で確認

5. アプリにログインして設定を入力

  1. MTG 録音メモ を開く
  2. 管理者から案内された 利用者ID と パスワード でログイン
  3. 「⚙️ 設定」を開く
  4. 以下を入力:
    • 利用者名 — 会社名や担当者名など、識別しやすい名前
    • Gemini API キー — ステップ 1 で取得したキー
    • スプレッドシート ID — ステップ 2 で取得した ID
    • Notion DB ID — ステップ 3-2 で取得した ID（任意）
    • Notion トークン — ステップ 3-1 で取得したトークン（任意）
  5. 「💾 保存」をクリック
  6. 「🔗 接続テスト」を押して、保存先にテストデータが追加されることを確認
設定はログイン中の利用者情報として保存されます。別のPCやブラウザからでも、同じIDでログインすれば設定を引き継げます。
NotionトークンやGemini APIキーは保存後に画面へ再表示されません。変更したい場合だけ、新しい値を入力して保存してください。

6. 使い方

  1. クライアント名を入力（話すか直接入力）
  2. MTG 日を選択（デフォルトは今日）
  3. 「🎙️ 録音開始」→ MTG を話す → 「■ 停止」
  4. 「✨ AI要約 & 保存」を押す

よくある質問

マイクが使えないと言われる

ブラウザのマイク権限を許可してください。Chrome の場合、アドレスバー左のアイコン → 「マイク」→「許可」です。

何回まで使える？

Gemini 無料枠は 1 日 1,500 リクエスト程度です。個人利用なら十分です。

データはどこに保存される？

音声データはブラウザ内のみ。テキストと要約はログイン中の利用者設定に紐づいた保存先（スプレッドシート / Notion）に送信されます。

コストは？

基本無料です（Gemini API 無料枠 + Notion 無料プラン + Google Apps Script 無料枠）。

スマホのホーム画面に追加したい

iPhone: Safari でアプリを開く → 共有ボタン → 「ホーム画面に追加」
Android: Chrome でアプリを開く → メニュー → 「ホーム画面に追加」

設定値はログイン中の利用者情報として保存されます。ブラウザにはログイン状態のみ保存され、NotionトークンやGemini APIキーは再表示されません。
