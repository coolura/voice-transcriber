MTG 録音メモ - セットアップガイド

初回設定の手順です。5〜10 分で完了します。

このアプリでできること

  • ブラウザだけで MTG を録音・文字起こし
  • AI（Gemini）が自動で議事録を要約
  • Google スプレッドシート / Notion に自動保存

アプリのインストールは不要です。Chrome または Edge でアクセスするだけで使えます。

1. Gemini API キーの取得

AI 要約に使う Gemini API のキーを取得します。

  1. Google AI Studio を開く
  2. Google アカウントでログイン
  3. 「API キーを作成」をクリック
  4. 表示された AIza... で始まるキーをコピー
無料枠で十分です。個人利用で課金される心配はありません。
API キーはパスワードと同じです。他人に教えないでください。紛失した場合は再発行できます。

2. スプレッドシートの準備

MTG 記録の保存先となるスプレッドシートを用意します。

  1. 新しいスプレッドシート を作成（名前は任意）
  2. ブラウザ上部の URL を確認
  3. /d/ と /edit の間にある長い文字列をコピー

URL の例:

https://docs.google.com/spreadsheets/d/1abcDEFghiJKLMnopQRstuVWxyz/edit#gid=0

この場合、スプレッドシート ID は 1abcDEFghiJKLMnopQRstuVWxyz です。

シート名やヘッダーは自動作成されます。スプレッドシートの中身を編集する必要はありません。

3. Notion の設定（Notion に保存する場合）

Notion に保存しない場合はスキップできます。

3-1. Notion トークンの取得

  1. Notion インテグレーション を開く
  2. 「新しいインテグレーション」をクリック
  3. 名前を入力し、ワークスペースを選択して作成
  4. 作成後の画面で「内部インテグレーションシークレット」をコピー

コピーした ntn_... で始まる文字列が Notion トークンです。

トークンはパスワードと同じ扱いです。他人に教えないでください。

3-2. Notion DB ID の取得

  1. Notion で保存先にするデータベースを開く
  2. 右上の「…」→「接続」から、作成したインテグレーションを追加
  3. データベースの URL をコピー
  4. URL 末尾の 32 文字の英数字が DB ID です

URL の例:

https://www.notion.so/example/36b1e4c4319e80c3bb45f8e6251a16f9?v=xxx

この場合、DB ID は 36b1e4c4319e80c3bb45f8e6251a16f9 です。

データベースにはタイトル型のプロパティ「名前」を用意してください。

4. アプリに設定を入力

  1. MTG 録音メモ を開く
  2. 「⚙️ 設定」を開く
  3. 以下を入力:
    • Gemini API キー — ステップ 1 で取得したキー
    • スプレッドシート ID — ステップ 2 で取得した ID
    • Notion DB ID — ステップ 3-2 で取得した ID（任意）
    • Notion トークン — ステップ 3-1 で取得したトークン（任意）
  4. 「💾 保存」をクリック
  5. 「🔗 接続テスト」を押して、保存先にテストデータが追加されることを確認

5. 使い方

  1. クライアント名を入力（話すか直接入力）
  2. MTG 日を選択（デフォルトは今日）
  3. 「🎙️ 録音開始」→ MTG を話す → 「■ 停止」
  4. 「✨ AI要約 & 保存」を押す

よくある質問

マイクが使えないと言われる

ブラウザのマイク権限を許可してください。Chrome の場合、アドレスバー左のアイコン → 「マイク」→「許可」です。

何回まで使える？

Gemini 無料枠は 1 日 1,500 リクエスト程度です。個人利用なら十分です。

データはどこに保存される？

音声データはブラウザ内のみ。テキストと要約は設定した保存先（スプレッドシート / Notion）に送信されます。

コストは？

基本無料です（Gemini API 無料枠 + Notion 無料プラン + Google Apps Script 無料枠）。

スマホのホーム画面に追加したい

iPhone: Safari でアプリを開く → 共有ボタン → 「ホーム画面に追加」
Android: Chrome でアプリを開く → メニュー → 「ホーム画面に追加」

設定値はすべてお使いのブラウザにのみ保存されます。外部に送信されるのは AI 要約時と保存先への送信時のみです。
